# Presentation-ready wording

## Recommended claim

> We developed an open, extensible MIWAE Corpus Analysis API. It accepts text, PDF, DOCX, and structured corpus inputs and generates transparent candidate profiles for MIWAE functions, grammatical forms, and their normalized distribution across segments. It can also import authorized Text Inspector exports and user-supplied EVP/EGP reference mappings. Automatic hits are verified contextually before interpretation.

## Avoid these claims

- “The API automatically determines whether a textbook is ELFA-friendly.”
- “The API is officially connected to Text Inspector or English Profile.”
- “The API uses the complete EVP/EGP databases.”
- “The automatic categories are error-free.”

## Short slide label

**Open research prototype · transparent candidate detection · optional authorized adapters · human verification**
